# zk-sovereignty-japan

Welcome to our primary development hub. We specialize in system-level development with a focus on privacy, security, and digital sovereignty.

## 🛠 Technical Focus

- **Languages:** High-performance systems programming using **Zig** and C.
- **Cryptography:** Zero-Knowledge Proofs (ZKP) and Self-Sovereign Identity (SSI) protocols.
- **Infrastructure:** Linux kernel optimization and secure-by-default management models.

## 🔐 Security & Reliability

Our development workflow follows a centralized vault model, ensuring all sensitive configurations and cryptographic keys are managed independently from public infrastructure.

## 🇯🇵 日本語 / Japanese

システムレベルのツール開発とセキュアなインフラ構築を専門とする開発組織です。
